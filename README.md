# zone-presence-detector-iot

Устройство предназначено для интегрирования с умным  домом и выполнения автоматизаций, в зависимости от того, в какой зоне комнаты находится человек. Также устройство может вести фотофиксацию происходящего в комнате.
<hr>
Устройство сканирует пространство перед собой и получает координаты людей, далее в зависимости от их местонахождения устройство способно посылать соответствующие команды в SmartThings, для выполнения определенных действий. Также реализовано общение между устройством и мобильным приложением, для того чтобы можно было настраивать устройство и взаимодействовать с ним через визуально приятный интерфейс. С мобильного приложения есть возможность подключить устройство к SmartThings; настроить зоны срабатывания датчика; настроить действие на обнаружение человека в зоне; получить фотографию с устройства в реальном времени; посмотреть что в данный момент видит датчик.
